# Mini Shopping Mall — brand kit

Everything here is generated by [`tools/build-logo.mjs`](../../tools/build-logo.mjs).
Edit that file, then:

```bash
npm run logo:png
```

`npm run logo` writes the SVGs only; `logo:png` also rasterises the PNG exports.

## Files

| File | Use |
| --- | --- |
| `icon.svg` / `icon-1024.png` | Primary app icon (store listing, launcher) |
| `icon-512/192/180.png` | Play Store, PWA, iOS home screen |
| `icon-simple.svg` / `favicon-32/64.png` | Small sizes — props and window detail stripped so it stays readable below ~40px |
| `icon-sunset.svg` | Alternate colourway (seasonal skins, A/B store icon tests) |
| `wordmark.svg` | Title screen, splash |
| `logo-lockup.svg` | Horizontal icon + wordmark: website header, press kit, README |
| `preview.html` | Open in a browser to see every asset at real sizes |

## Palette — "Sky" (primary)

| Role | Hex | Notes |
| --- | --- | --- |
| Sky light / dark | `#7CD9FF` → `#2A6FD6` | Icon background radial gradient |
| Mall white | `#FFFFFF` / `#EFF4FB` / `#D7E2F1` | Top / right / left faces of the base floor |
| Gold trim | `#FFC53D` / `#F2AC28` / `#DC961A` | Cornice, billboard, currency, primary CTA |
| Mall pink | `#FF7BA6` / `#F25F8F` / `#D9457A` | Upper floor, awnings, shopper |
| Glass | `#7FD4FF` / `#CDEEFF` | Shopfront windows |
| Money green | `#5FE08D` / `#41C673` / `#2CA85C` | Cash, income numbers, "earned" state |
| Ink | `#16295C` | Text on gold, outlines, drop shadows at 13–20% |

Alternate "Sunset" swaps the sky for `#FFC46B → #F4633F` and the pink floor for
teal `#3FD4CB`. Both palettes live at the top of the generator.

**Face shading rule:** every isometric solid uses three tints of one colour —
top is the base, the right face one step darker, the left face two steps.
Keep that order for any new prop so it sits in the same light.

## Type

Chunky rounded geometric sans, weight 800: **Baloo 2** (first choice),
falling back to Fredoka → Nunito → system UI. The wordmark treatment is
white fill, `#16295C` outline at 16px, and a gold slab offset 16px down.

The SVGs reference the font by name, so a machine without Baloo 2 renders the
fallback. **Before shipping the wordmark anywhere public, convert the text to
outlines** (Illustrator/Inkscape "Object to Path") so it is pixel-identical
everywhere — the generator intentionally keeps live text so the tagline stays
editable while the game is in development.

## Do / don't

- Do keep the icon's ~114px corner radius (on a 512 grid) — it matches the iOS squircle closely enough and Android masks it anyway.
- Do use `icon-simple` anywhere under 40px. The full icon's shopper and windows turn to mud.
- Don't put the wordmark on a busy screenshot without the navy outline — that outline is what carries it.
- Don't recolour the money green. It is the one colour that means "income" across the UI.
